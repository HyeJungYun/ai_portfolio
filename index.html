오늘의 커리어 맵핑이란?

새로운 활동을 따로 하지 않아요. 실습에서 내 프로젝트와 활동을 대시보드에 모으면, AI가 각 기록의 내 역할과 역량을 정리해 줘요. 이렇게 쌓인 기록을 한눈에 보면 "내가 무엇을 해 왔고, 어떤 직무로 이어지는지"가 보이는데, 이것이 오늘 만드는 나만의 커리어 맵이에요.

이미 노션을 쓰고 있다면: 실습 전용 워크스페이스 추천

AI 연결은 페이지 단위가 아니라 워크스페이스 전체 단위예요. 기존 메모·일기가 있는 공간을 연결하기 부담스러우면, 사이드바 왼쪽 위 워크스페이스 이름 → + 새 워크스페이스로 실습 전용 공간을 하나 만들어 그걸 연결하세요. 무료이고 개수 제한도 없어요. 이름은 설정 → 일반에서 "○○의 포트폴리오"처럼 바꿀 수 있어요.

체크 표시와 실습 단계의 "완료" 표시는 이 브라우저에만 저장돼요.

AI에 노션 연결하기

목표: Claude가 내 노션에 페이지를 만들 수 있는지 확인한다.

  1. 1

    claude.ai 왼쪽 사이드바의 플러그인(또는 내 이름 → 설정 → 플러그인)에서 Notion을 찾아 연결을 눌러요.

  2. 2

    노션 인증 창이 뜨면 내 워크스페이스를 고르고 계속하기로 접근을 허용해요. 연결은 고른 워크스페이스 전체에 적용돼요 — 페이지만 골라서 연결할 수는 없어요. 실습 전용 워크스페이스를 만들었다면 여기서 그걸 선택하세요. 다른 워크스페이스로 바꾸고 싶으면 플러그인에서 Notion을 연결 해제한 뒤 다시 연결하면서 고르면 돼요.

  3. 3

    새 대화에서 아래 테스트 프롬프트를 보내요. AI가 노션 작업 허락을 물으면 내용을 읽고 한 번 허용을 눌러요. 항상 허용은 누르지 마세요 — 무엇을 만드는지 보면서 허용하는 게 오늘의 원칙이에요.

    테스트 프롬프트
    내 노션에 "연결 테스트"라는 페이지를 만들고, 본문에 오늘 날짜를 한 줄 써 줘.
만든 페이지 링크를 알려 주고, 실제로 만들지 못했다면 만들었다고 하지 말고 이유를 알려 줘.
  4. 4

    노션 사이드바에 "연결 테스트" 페이지가 생겼는지 확인하고, 확인했으면 지워요.

ChatGPT로 할 때

ChatGPT 설정의 앱(플러그인) 메뉴에서 Notion을 연결하면 같은 프롬프트를 쓸 수 있어요. 노션에 쓰기 전마다 승인 버튼이 뜹니다. 메뉴 이름은 업데이트에 따라 조금 다를 수 있어요.

권한 주의

AI는 내 노션 권한 그대로 움직여요. 처음에는 쓰기 작업마다 승인하도록 두고, 무엇을 만드는지 보면서 허용하세요.

오늘의 핵심 습관: 시키기 → 직접 확인

AI의 "다 했어요"라는 답과 실제 노션은 다를 수 있어요. AI가 무언가를 만들었다고 하면 반드시 노션을 직접 열어 눈으로 확인해요. 오늘 모든 실습이 이 순서로 진행됩니다.

무료 사용량은 대화가 오갈수록 빨리 줄어요. 원하는 구조를 한 프롬프트에 다 적으면 사용량도 아끼고 결과도 더 일정해요.

    만든 이미지를 대시보드 커버로 넣는 법
    • 이미지에 마우스를 올려 다운로드(↓)로 저장해요 (아이콘이 없으면 이미지 우클릭 → 다른 이름으로 저장)
    • 노션에서 "[이름] 포트폴리오" 대시보드를 열어요 — 프로젝트 페이지가 아니라 맨 바깥 페이지예요
    • 커버가 없으면: 제목 바로 위 빈 공간에 마우스 → 커버 추가
    • 커버 위에 마우스를 올리면 오른쪽 아래에 버튼이 떠요 → 커버 변경 → 업로드 → 방금 받은 파일 선택
    • 위치 변경을 눌러 위아래로 끌어 보기 좋은 부분을 맞추고 저장해요. 노션 커버는 가운데 가로 띠만 보여요
  3. 3

    • 조심해서: 이메일 — 수업에서는 빼고, 나중에 취업용으로 꼭 필요할 때만 추가해요
    • 프로젝트 본문도 확인: 팀원 실명·연락처, 회사·기관의 비공개 자료가 들어가지 않았는지

3단계. 노션에서 직접 다듬기

  1. 1

    날짜·시간 바꾸기: 캘린더에서 일정을 열고 날짜를 클릭해요. 종료일을 켜면 기간으로, 시간 포함을 켜면 시간까지 넣을 수 있어요.

    예: "경영통계 회귀분석 문제 풀이"를 12.4에서 12.5로 끌어 옮기면, "📝 학습 메모" 탭의 날짜도 같이 바뀌어요.

  2. 2

    구분·메모가 캘린더에 안 보이면: 캘린더 오른쪽 위 ••• → 속성에서 "구분"과 "메모" 옆 눈 아이콘을 켜요.

    예: 캘린더 칸에 "경영통계 회귀분석 문제 풀이" 아래 학습계획 · 기출 문제 10개 풀기, "동계방학 시작" 아래 학사일정이 함께 보여요.

  3. 3

    표·타임라인 보기 추가: 보기 탭 옆 +를 눌러 표와 타임라인을 추가해요. 데이터는 그대로이고 보는 모양만 바뀌어요.

    예: 타임라인에서는 "2학기 기말고사 12.15~12.21"처럼 기간이 있는 일정이 긴 막대로 보여서 시험 주간이 한눈에 들어와요.

  4. 4

    같은 이름이 두 번 보이면: AI가 데이터베이스를 따로 만들고(▦ 한 줄 링크) 그 아래에 링크된 보기(↗ 붙은 캘린더)를 얹은 경우예요. ▦ 줄 왼쪽 ⋮⋮ → 인라인으로 전환을 눌러 캘린더가 페이지 안에 바로 보이게 한 뒤, ↗ 블록은 ⋮⋮ → 삭제해요. ↗는 보기일 뿐이라 지워도 일정은 그대로예요. ▦ 줄(원본)은 지우지 마세요. 지우면 일정이 모두 사라져요(휴지통에서 복원은 돼요).

    예: 정리하면 페이지 제목 아래에 "학사일정 & 학습계획" 하나만 있고, 그 안에 📅 캘린더 · 📝 학습 메모 탭이 보여요. 탭이 없으면 보기 탭 옆 + → 표로 "📝 학습 메모"를 만들고, 필터 구분 = 학습계획, 정렬 날짜 오름차순을 골라요.

ChatGPT는 노션에 쓸 때마다 승인 버튼이 떠요. 내용을 읽고 눌러 주세요. 연결이 막히면 노션 빈 페이지에서 /캘린더 → 캘린더 보기를 골라 직접 만들고, 새로 만들기나 날짜 칸의 +로 일정을 넣으면 돼요.
